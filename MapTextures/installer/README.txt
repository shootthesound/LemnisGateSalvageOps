Lemnis Gate - Salvage Ops map textures

Adds textures to the untextured prototype maps and sets up developer mode (the P2P menu).

INSTALL
1. Run the game once through Steam and quit from the main menu (first time only).
2. Unzip this folder anywhere and double-click Install.bat.
3. Pick your Lemnis Gate folder (usually ...\steamapps\common\LemnisGate) and click OK.

PLAY
Start the game with the "Lemnis Gate (Salvage Ops)" desktop shortcut while Steam is running.
Launching through Steam starts EasyAntiCheat, which hides the textures.
Multiplayer works as before: P2P (DEV) > Create Session, and the other player hits refresh.
Everyone in a match should start the game the same way.

UNINSTALL
Double-click Uninstall.bat. Developer mode is left on.
